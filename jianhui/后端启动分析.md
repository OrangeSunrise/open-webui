# 后端启动分析：dev.sh 会发生什么

> 记录时间：2026-09-02。所有结论均已从源码验证（标注 文件:行号）。
> 环境：`backend/.venv`（Python 3.11.16，uv 管理，Windows），依赖已按 requirements.txt 全量安装（340 包，走 tuna 镜像）。

---

## 一、dev.sh 逐行解读

```bash
export CORS_ALLOW_ORIGIN="http://localhost:5173;http://localhost:8080"   # 允许 Vite 前端(5173)跨域调 API
PORT="${PORT:-8080}"                                                      # 端口，可用 PORT=8090 sh dev.sh 覆盖
uvicorn open_webui.main:app --port 8080 --host 0.0.0.0 ... --reload       # 启动 ASGI 开发服务器
```

- `--reload`：修改 `backend/open_webui` 下的 Python 代码自动重启（开发模式核心）
- `--host 0.0.0.0`：局域网内其他设备可访问；首次运行可能触发 Windows 防火墙弹窗，允许"专用网络"即可
- ⚠️ **脚本本身不激活 venv**——它假设当前 shell 已激活 `.venv`

## 四、问答记录

### 问1：启动后端会加载哪些模型？会下载模型吗？

**答：启动时不加载、不下载任何 AI 模型。**

代码证据：`main.py:645` 启动时只做 `app.state.ef = None`——embedding 模型在 `get_ef()`（`retrieval.py:157`）里实例化，只在第一次用到 RAG 功能的请求时被调用；Whisper 同理在转写接口内部（`audio.py:229`）。启动慢纯粹是 import 大包。

各功能模型加载时机（默认配置）：

| 功能 | 模型 | 何时加载 | 会下载吗 |
|---|---|---|---|
| RAG 向量化 | `sentence-transformers/all-MiniLM-L6-v2`（默认引擎=本地） | 第一次上传文档/建知识库时 | ✅ 约 90MB → `~/.cache/huggingface` |
| RAG 重排序 | 默认**关闭**（`RAG_RERANKING_MODEL=''`） | 配置了才加载 | 配置后首次用时下载 |
| 语音转文字 | faster-whisper `base` | 第一次录音/传音频时 | ✅ 约 150MB → `backend/data/cache/whisper/models`（`config.py:1550`） |
| 语音合成 | 无本地模型（`AUDIO_TTS_ENGINE=''`，走外部 API/浏览器） | — | ❌ |
| 图像生成 | 无本地模型（`IMAGE_GENERATION_ENGINE` 默认 `openai`，远程 API） | — | ❌ |
| OCR | rapidocr，模型**内置在安装的包里** | 第一次识别图片文字时 | ❌ 零下载 |
| token 计数 | tiktoken BPE 词表 | 第一次用到 | ✅ 约 2MB，缓存后离线 |
| 文档切块 | nltk punkt 数据 | unstructured 首次解析文档时 | ✅ 几 MB → `~/nltk_data` |

**纯聊天（OpenAI 兼容 API 模式）从头到尾不需要任何本地模型。**

### 问2：后端启动的时候会下载数据库服务吗？

**答：不会，零下载。**

- 默认两个数据库都是**嵌入式**的：
  - **SQLite**：引擎内置于 Python 标准库（`sqlite3` 模块），启动时只是创建本地文件 `backend/data/webui.db`
  - **ChromaDB**：数据库本体就是已安装的 `chromadb` Python 包，随进程运行，在本地建存储文件
- requirements.txt 里的 `pymongo`/`psycopg`/`PyMySQL`/`qdrant-client`/`elasticsearch`/`redis` 等全是**客户端连接器**，不含服务端，默认配置下启动时完全躺平
- 哪天要换 PostgreSQL/MySQL/Milvus 等，需要**自己另行部署服务端**（通常 Docker），再用环境变量（`DATABASE_URL`、`VECTOR_DB`、`REDIS_URL`）让 Open WebUI 去连

**启动期仅有的网络活动**：Ollama 探测（本地连接）+ ChromaDB 匿名遥测（PostHog）。想关遥测：`backend/.env` 写一行 `ANONYMIZED_TELEMETRY=false`。

**国内网络提示**：第一次用 RAG 时会从 HuggingFace 下载 90MB 模型，可能很慢。建议 `backend/.env` 加一行 `HF_ENDPOINT=https://hf-mirror.com` 走镜像。

## 五、失败点速查

| 报错 | 原因 | 解决 |
|---|---|---|
| `uvicorn : 无法将"uvicorn"识别为…` | venv 没激活（或激活的不是跑命令的那个终端） | 先激活再跑 |
| `[Errno 10048] address already in use` | 8080 被占 | 换 `PORT=8090` 或找到占用进程 |
| 启动超过 1 分钟没动静 | 大概率在 import 大包 | 再等等 |
| `libGL.so.1` 缺失 | 仅 WSL2/Linux（opencv 完整版） | `sudo apt install libgl1`；Windows 不会遇到 |

## 六、启动之后的下一步

1. 另开一个终端跑前端：仓库根目录 `npm install && npm run dev` → `http://localhost:5173`
2. 浏览器访问 `http://localhost:5173`，首次进入会引导创建管理员账号
3. 在管理面板配置模型连接（OpenAI 兼容 API 或 Ollama）
