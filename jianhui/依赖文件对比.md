# pyproject.toml / requirements.txt / requirements-min.txt 依赖对比

> 对比时间：2026-09-02（脚本逐包核对）
> 三个文件：根目录 `pyproject.toml` 的 `[project] dependencies`、`backend/requirements.txt`、`backend/requirements-min.txt`
> 结论先行：**requirements.txt（125 包）是功能最全的安装清单；pyproject.toml 主依赖（99 包）少了可选组和追踪/多媒体包；requirements-min.txt（46 包）是砍掉 79 个包的"最小运行"参考，但目前未锁版本且砍了仍在被代码 import 的包，装上大概率起不来（文件头也自注 WIP）。**

---

## 一、三个文件的定位

| | `pyproject.toml` | `backend/requirements.txt` | `backend/requirements-min.txt` |
|---|---|---|---|
| 用途 | Python 包打包/发布定义（uv、pip、hatchling 读取） | 直接 `pip install -r`（Docker 构建、`dev.sh`、官方开发文档） | "最小可运行后端"参考，目标用于构建精简 Docker 镜像 |
| 包数量 | 主依赖 99 + 可选组 | 125 | 46 |
| 可选依赖 | 按 extras 分组：`postgres`/`mariadb`/`unstructured`/`all` | 全部平铺装入（mariadb 仅注释） | 无，只保留启动必需 |
| 仓库内引用 | 打包/CI 使用 | Dockerfile / dev.sh / 官方文档 | **零引用**（无任何 Dockerfile 或脚本使用，头注释自注 `# WIP`） |

### 2. requirements.txt 中有、pyproject 中完全没有的 13 个包 ⚠️

**OpenTelemetry 链路追踪全家桶（12 个，1.42.1 / 0.63b1 成对）：**

```text
opentelemetry-api / opentelemetry-sdk / opentelemetry-exporter-otlp（==1.42.1）
opentelemetry-instrumentation{,-fastapi,-sqlalchemy,-redis,-requests,-logging,-httpx,-aiohttp-client,-system-metrics}（==0.63b1）
```

**多媒体解码：**

```text
av==14.0.1  # 因 FIPS SELFTEST FAILURE 锁定 14.x
```

> 意义：用 `uv sync`（走 pyproject）装环境，启用 `ENABLE_OTEL=true` 的链路追踪和部分音视频处理会缺依赖；走 requirements.txt 无此问题。

### 3. pyproject 中有、requirements.txt 中没有的 1 个包

| 包 | 版本 | 说明 |
|---|---|---|
| mariadb | 1.1.14 | pyproject 可选组 `[mariadb]`；requirements.txt 中仅一行注释 |

### 4. 版本一致性

前两者共有的约 99 个包**版本号完全一致，零冲突**（仅个别行内注释措辞不同）。

## 三、requirements-min.txt 单独分析 ⚠️

文件头：`# Minimal requirements for backend to run` / `# WIP: use this as a reference to build a minimal docker image`

### 1. 保留了什么（46 个包）

Web 框架（fastapi/uvicorn/pydantic/socketio）、认证栈（cryptography/bcrypt/argon2/PyJWT/authlib/joserfc）、HTTP 客户端（requests/aiohttp/httpx）、SQLite+Postgres 数据库基础（sqlalchemy/aiosqlite/psycopg/alembic）、redis、pycrdt、APScheduler、RestrictedPython、loguru、mcp、**仅 openai 一家 AI 提供商**、langchain 四件套、**仅 chromadb 一个向量库**（默认 RAG 后端）、black、pydub、chardet、beautifulsoup4、fake-useragent。

### 2. 砍掉的 79 个包（相对 requirements.txt）

| 类别 | 砍掉的包 |
|---|---|
| AI 提供商/工具 | anthropic、google-genai、tiktoken、regex、ddgs、youtube-transcript-api、pytube |
| RAG/文档处理 | pypdf、fpdf2、python-docx、python-pptx、unstructured、nltk、pandas、openpyxl、xlrd、pyxlsb、pypandoc、lxml、ftfy、pymdown-extensions、docx2txt、msoffcrypto-tool、sentencepiece |
| 向量库/搜索后端 | weaviate-client、opensearch-py、pymilvus、qdrant-client、elasticsearch、pinecone、oracledb、boto3 |
| 数据库驱动 | pymongo、psycopg2-binary、pgvector、pymysql |
| OCR/视觉/音频 | pillow、opencv-python-headless、rapidocr、rank-bm25、onnxruntime、faster-whisper、av、soundfile |
| 云服务集成 | azure-*（4 个）、google-api-* / google-auth-* / google-cloud-storage（5 个） |
| ML 基础库 | transformers、sentence-transformers、accelerate、pyarrow、einops、colbert-ai |
| 链路追踪 | opentelemetry 全家桶 12 个 |
| 其他 | pytz、markdown、aiodns、python-mimeparse、psutil、validators、ldap3、playwright |

### 3. 三个问题 ⚠️

**① 砍掉的包仍有 6 个核心模块在直接 import，装完大概率启动失败：**

| 模块 | import 的被砍包 | 说明 |
|---|---|---|
| `routers/auths.py`、`utils/auth.py` | tiktoken、validators 等 | 认证路由，启动即挂载 |
| `routers/images.py` | PIL（pillow） | 图像路由，启动即挂载 |
| `routers/retrieval.py`、`retrieval/loaders/main.py` | pandas、ftfy、validators 等 | RAG 路由与加载器，启动即挂载 |
| `utils/pdf_generator.py` | fpdf 相关 | PDF 导出 |
| 其他 | pytz、markdown、regex、ldap3 | LDAP 登录用时也会缺 |

（FastAPI 的路由在 `main.py` 启动时统一挂载，import 失败 = 后端起不来）

**② 9 个包未锁版本**（requirements.txt 中都是精确锁定的）：cryptography、async-timeout、aiocache、aiofiles、redis、hiredis、openai、pydub、beautifulsoup4 —— 构建不可复现，与"做最小镜像"的目标矛盾。

**③ `sqlalchemy` 少了 `[asyncio]` extra**：min 写 `sqlalchemy==2.0.50`，requirements.txt / pyproject 写 `sqlalchemy[asyncio]==2.0.50`。该 extra 负责安装 greenlet，SQLAlchemy 异步引擎（本项目用 aiosqlite 异步）缺它会报 MissingGreenlet 类错误。

### 4. 保留部分的版本

两边都锁定的版本号与 requirements.txt **完全一致，零冲突**。

## 四、对本机开发的实际影响

按 `jianhui/运行说明.md` 的方案（`uv venv` + `uv pip install -r requirements.txt`）：

- 装的是 requirements.txt = **Docker 镜像同款依赖**，包含全部向量库/追踪/多媒体支持，不会有 `uv sync` 缺 opentelemetry、av 的问题，更不要用 requirements-min.txt。
- 副作用是多装一批用不到的可选后端依赖（pymongo、qdrant、elasticsearch 等），安装体积更大；如需精简，可注释掉「二、1 节」表格中用不到的向量库包再安装，但**不要照抄 requirements-min.txt**（见三、3 的三个问题）。
- 唯一反向差异是 mariadb：requirements.txt 默认不装，要连 MariaDB 需手动补 `uv pip install mariadb==1.1.14`。
