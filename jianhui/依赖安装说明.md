# requirements.txt 安装说明：装什么、多大影响、每个包干什么

> 基于 2026-09-01 的 `backend/requirements.txt`（125 个直接锁定包）。
> 已用 uv 在 Python 3.11.16 虚拟环境中实际 dry-run 解析：**最终会安装 340 个包**（125 直接 + 约 215 个传递依赖）。
> 结论：按 `jianhui/运行说明.md` 的方案装在 venv 里，对系统零污染，删目录即完全卸载；磁盘占用 GB 级，大头是 torch 系。

---

## 一、总体影响

| 项目 | 数值 | 说明 |
|---|---|---|
| 直接依赖 | 125 个 | requirements.txt 里逐行写死 `==` 版本的 |
| 传递依赖 | 约 215 个 | 由上面 125 个自动拉入，**未锁版本**，随时间会漂移 |
| 总安装量 | **340 个包** | uv 实测解析结果（Windows + Python 3.11.16） |
| 磁盘占用（估算） | Windows 约 4–6 GB；WSL2 约 8–12 GB | 最大单一依赖是 torch（仅它就 1GB+）；Linux 默认装 CUDA 版 torch + 一整套 nvidia 库，所以翻倍 |
| 对系统的影响 | 无 | 装在 `backend/.venv` 内，不动系统 Python；想清理直接删 `.venv` 目录 |
| 下载源 | 清华 tuna 镜像 | 根目录 `pyproject.toml` 已配置为默认 index |

WSL2 下包数量与 Windows 略有出入（平台差异：Linux 多 `uvloop`，少 `pywin32`/`win32-setctime`），总量级一致。

## 三、传递依赖里值得认识的大块头

解析出的 340 个包中，这些不是 requirements.txt 直接写的，而是被自动拉入的：

| 传递依赖 | 谁拉进来的 | 体量 |
|---|---|---|
| **torch==2.13.0** | transformers / sentence-transformers / colbert-ai | 最大，装完 1GB+；Linux 上默认是 CUDA 版，还会带 12+ 个 `nvidia-*` 包 |

## 四、装完之后还会发生什么（运行时）

这些不是安装期的事，但属于"装了这个 txt"的完整影响：

| 时机 | 会发生什么 | 触发条件 |
|---|---|---|
| 首次用到本地 Embedding / 本地 Whisper | 从 HuggingFace 下载模型（GB 级，缓存在 `~/.cache/huggingface`） | 仅当不使用远程 API embedding 时 |
| 首次用到 NLTK 分句 | 自动下载分词数据 | 文档解析时 |
| 用 pypandoc 转换文档 | 需要 pandoc 二进制，WSL2 里 `sudo apt install pandoc` | 仅用到对应格式转换 |
| 启用浏览器抓取 | 需要 `playwright install chromium` | 仅网页抓取功能 |
| tiktoken 首次计数 | 联网拉一次 BPE 词表后缓存 | 自动 |

默认配置（OpenAI 兼容 API + 远程 embedding）下，以上全部不会触发。

## 五、如果不想全装（精简建议）

直接在 requirements.txt 里注释掉整组即可，**后端默认功能（聊天 + chromadb RAG）不受影响**：

1. **收益最大**：`colbert-ai` + `transformers/sentence-transformers/accelerate/einops` + `onnxruntime` + `faster-whisper` —— 注释掉可省掉 torch/spacy/scipy/sklearn 一大串（约省 2–4 GB），代价是不能用本地 embedding/本地 Whisper/ColBERT 重排
2. **其他向量库**：weaviate-client、opensearch-py、pymilvus、qdrant-client、elasticsearch、pinecone、oracledb、pymongo —— 只用默认 chromadb 就全可注释
3. **云服务**：azure-\*、google-\*、boto3、ldap3 —— 不接云盘/S3/域账号就可注释
4. **追踪**：opentelemetry 全家桶 12 个 —— 不接追踪平台可注释
5. **YouTube/抓取**：pytube、youtube-transcript-api、playwright —— 不爬网页可注释

⚠️ 不要参考 `requirements-min.txt` 精简——它连 tiktoken、pillow、validators 这类启动必需的包都砍了，装上起不来（详见 `依赖文件对比.md` 第三节）。

## 六、与其他两个文件的关系

- 本文件（requirements.txt）= **Docker 镜像同款全量依赖**，125 直接/340 总量
- `pyproject.toml` = 打包定义，主依赖 99 个，少 opentelemetry×12 和 av，多 mariadb 可选组 → 详见 `依赖文件对比.md`
- `requirements-min.txt` = 砍过头的 WIP 参考，当前不可用 → 同上
